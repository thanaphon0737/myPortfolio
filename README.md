# My Portfolio

A modern portfolio website built with **Next.js** and **Tailwind CSS**.

## Tech Stack

- **Framework**: Next.js
- **Styling**: Tailwind CSS
- **Deployment**: Vercel

## Features

- Responsive design
- Fast performance
- Clean and minimal UI
- Easy to customize

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
